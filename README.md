# AI-Powered Threat Detection System

## Overview
An ML-based security threat detection system that analyzes Azure logs
and identifies malicious activity using Random Forest classification.

## Features
- Machine Learning threat detection
- Real-time log analysis
- Automated security alerts
- Azure Log Analytics integration

## Technologies
- Python 3.13
- scikit-learn (Random Forest)
- Azure Monitor / Sentinel
- Pandas, NumPy

## Project Structure
- data/ — Sample security log data
- models/ — Trained ML model
- scripts/ — Training and detection scripts
- alerts/ — Alert notification system

## How to Run
'''bash
pip install -r requirements.txt
python scripts/train_model.py
python scripts/detect_threats.py
'''
